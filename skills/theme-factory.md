# Theme Factory Skill

Toolkit for styling artifacts with a theme. Apply to slides, docs, reports, HTML pages, etc. 10 pre-set themes with colors/fonts, or generate a new theme on-the-fly.

## Usage

1. **Show themes**: Present available themes for user to review
2. **Ask for choice**: Get explicit confirmation about chosen theme
3. **Apply theme**: Apply selected colors and fonts consistently throughout the artifact

## Application Process

After theme is selected:
1. Read the theme's color palette and font pairings
2. Apply colors and fonts consistently throughout the artifact
3. Ensure proper contrast and readability
4. Maintain the theme's visual identity across all slides/pages

## Create Custom Theme

When none of the pre-set themes fit:
1. Based on user inputs, choose appropriate colors/fonts
2. Define 4 colors: primary, secondary, accent, neutral
3. Select font pairing: header + body
4. Name the theme describing what the combination represents
5. Show for review before applying
